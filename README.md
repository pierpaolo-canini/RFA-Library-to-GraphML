# RFA-Library-to-GraphML
A GrahpML serializer for your Revit Family Library

[LinkedIn Post w/ Video](https://www.linkedin.com/posts/pierpaolocanini_create-a-network-graph-of-your-revit-library-activity-7284560454973100033--0XU?utm_source=share&utm_medium=member_desktop)

# How To
Use run the dynamo script on a list of Revit Families, you'll get the GraphML file in the script directory. Open The GraphML in the viewer you prefer. If you use Cytoscape, you can download a present style from the repo.
